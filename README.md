# TOP SPEED ONLINE — 2D top-down гонки с друзьями

Node.js + WebSocket (`ws`) на сервере, Canvas 2D в браузере. Сервер авторитетен: физика, столкновения, контрольные точки, круги, позиции и результаты считаются на сервере; клиент отправляет только нажатия клавиш и сам предсказывает свою машину (чужие — интерполяция).

## 1. Установка Node.js
Скачайте LTS-версию (18+) с https://nodejs.org и установите. Проверка: `node -v`.

## 2. Зависимости
```
cd top-speed-online
npm install
```

## 3. Пароль администратора
Ник `stleri` — это только имя админа, не секрет. Права выдаются сервером **только при верном пароле**.
```
cp .env.example .env      # Windows: copy .env.example .env
```
Откройте `.env` и задайте длинный `ADMIN_PASSWORD`. Пароль не попадает в клиентский код. Если пароль не задан — вход под `stleri` отключён (сервер напишет предупреждение). После 5 неверных попыток вход блокируется на минуту.
Можно и без файла: `ADMIN_PASSWORD=... npm start` (Linux/macOS) или `set ADMIN_PASSWORD=...` (Windows cmd).

## 4. Запуск
```
npm start
```
Откройте http://localhost:3000. Вводите ник `stleri` → появится поле пароля → после входа слева открывается админка.

## 5. Несколько игроков на одном компьютере
Откройте несколько вкладок (лучше окон) http://localhost:3000 с разными никами. Неактивная вкладка браузера замедляется — держите окна рядом.

## 6. Друзья через интернет
Сам по себе `npm start` на вашем ПК доступен **только вам** (и устройствам в вашей Wi-Fi-сети по `http://<ваш-локальный-IP>:3000`). Чтобы подключились друзья из интернета, нужен один из способов:
- **Туннель (проще всего):** `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000` — дадут публичный https-адрес; WebSocket пойдёт по нему автоматически (wss).
- **Проброс порта на роутере:** TCP 3000 → ваш ПК, затем друзья заходят на `http://<ваш-внешний-IP>:3000`. Работает не у всех провайдеров (нужен «белый» IP), требует настройки файрвола.
Админ-пароль по http передаётся открытым текстом — для интернета используйте туннель/хостинг с HTTPS.

## 7. Хостинг
Подойдёт любой хостинг с Node.js и поддержкой WebSocket (Render, Railway, Fly.io, VPS):
1. Загрузите проект (без `.env`), команда сборки `npm install`, запуск `npm start`.
2. В настройках сервиса задайте переменные `ADMIN_PASSWORD` (и при желании `LAPS`). `PORT` хостинг обычно задаёт сам.
3. Включите HTTPS (на большинстве платформ автоматически).
Бесплатные тарифы могут «засыпать» — комната и заезд при этом сбрасываются.

## Машины и цвет
В меню перед игрой выбирается кузов: Классика, Формула, Маскл, Пикап, Карт. Кузов — только внешний вид: физика, ускорение и максимальная скорость у всех одинаковые. Выбор запоминается.
Рядом — палитра из 32 цветов (или «Авто»): занятый цвет сервер не выдаст, поэтому у каждого игрока цвет всегда уникальный. Выбор тоже запоминается.

## Наблюдатели
Комната вмещает до 32 человек. Кнопка **СМОТРЕТЬ** в меню — вход в режим наблюдателя: машины нет, заезд не портится, видны таблица позиций, а после финиша — анимация победителя и повтор финиша. Наблюдателей видно в списке игроков («· наблюдает»).

Наблюдатель сам выбирает, за кем следить:
- кнопки в панели слева: **←** / **→** — предыдущий/следующий по позиции, **ТОП-1** — лидер, **ПОСЛЕДНИЙ** — замыкающий;
- клик по игроку в таблице справа;
- клавиатура: ←/→ листать, **L** — лидер, **E** — последний.
Панель показывает ник и цвет выбранного, его круг, место и время заезда; выбранная машина подсвечена на мини-карте. По умолчанию камера следует за лидером.

Важно: после входа все стоят на стартовой решётке — ехать нельзя, пока администратор (ник `stleri`) не нажмёт «НАЧАТЬ ГОНОЧНЫЙ ЗАЕЗД».

## Управление
- **Клавиатура:** W/↑ газ · S/↓ тормоз и задний ход · A/D или ←/→ руль · Space ручник (заносы) · R вернуть на последнюю контрольную точку.
- **Мышь** (галочка в настройках меню): W или ЛКМ — газ, S/↓ — тормоз, курсор задаёт направление — машина поворачивает к нему; Space ручник, R респаун.
- **Телефон/планшет:** слева виртуальный джойстик — руль (аналоговый), справа кнопки ГАЗ / ТОРМОЗ / РУЧНИК / СБРОС. Играть лучше в горизонтальной ориентации.

Дрифт: ручник на скорости + контрруль (руль в сторону заноса) удерживает машину в скольжении, из-под колёс идёт дым, на асфальте остаются следы. Удары о стены и машины — искры, дым и тряска экрана. Из выхлопных труб при газе выбивается огонь (и «хлопок» при сбросе газа); в настройках меню можно выбрать цвет дыма и цвет выхлопа/огня.

В панели слева считаются круг, контрольные точки (КП 0/8), позиция, время заезда, время текущего круга и лучший круг — всё тикает во время заезда после старта администратора. Пересечение финишной линии после всех контрольных точек даёт +1 круг (всплывает «КРУГ 2/3»); после последнего круга — «ФИНИШ», имя победителя объявляется на весь экран и в таблице результатов. Круг на трассе занимает ~40–50 секунд.

После финиша всем показывается **анимация победителя**: крупное имя победителя (в его цвете) и видеоповтор последних ~10 секунд заезда — сервер записывает позиции машин (15 кадров/с) и в момент финиша отдаёт этот отрезок; в повторе камера следит за машиной победителя (жёлтая подсветка). Повтор зациклен, закрывается кнопкой или клавишей Esc.

## Админ-команды (проверяются на сервере при каждой команде)
- **Начать гоночный заезд** — все на решётку → 3-2-1-GO → общий таймер.
- **Завершить гоночный заезд** — мягко: остальным даётся 15 с на финиш, затем результаты.
- **Завершить текущий заезд** — принудительно и сразу, с подтверждением (до старта отменяет отсчёт).
- **Перезапустить заезд** — всех на старт, таймер и круги сброшены, ожидание нового старта.
- **Вернуть всех на старт** — телепорт на решётку (только в ожидании/после результатов).

Игрок, зашедший во время заезда, наблюдает (полупрозрачная машина без столкновений) и участвует со следующего заезда.
